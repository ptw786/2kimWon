# 안심온 웹앱 시연판

기존 FastAPI 식사·수면 판정과 재질문을 웹 화면에 연결한 로컬 시연판입니다. 생활지원사 화면에서 완료 상태, 확인 우선순위, 판정 근거와 질문별 답변을 볼 수 있습니다. 기록은 SQLite에 저장합니다.

## Windows PowerShell에서 실행

1. GitHub에서 `taewon` 브랜치를 내려받고 VS Code에서 `main.py`가 있는 폴더를 엽니다.
2. **터미널 → 새 터미널**을 열고, 아래 명령을 한 줄씩 실행합니다. Python 3.10 이상이 필요합니다.

```powershell
py -m venv .venv
& ".\.venv\Scripts\python.exe" -m pip install -r requirements.txt
& ".\.venv\Scripts\python.exe" -m uvicorn main:app --host 127.0.0.1 --port 8000
```

`py`를 찾지 못하면 첫 줄을 `python -m venv .venv`로 실행합니다. 이미 사용하던 안심온 백엔드가 포트 8000을 쓰고 있다면 해당 터미널에서 `Ctrl+C`로 종료한 후 실행합니다.

3. 터미널을 켜 둔 채 브라우저에서 [안심온 열기](http://127.0.0.1:8000/)를 선택합니다. 질문과 기록 요청은 같은 FastAPI 서버가 처리합니다. 실행에 필요한 것은 Python 환경이며 OpenAI API 키는 필요 없습니다.

첨부된 `ansimon.db`가 포함되어 있어 기존 시연 기록에서 시작합니다. DB가 없으면 첫 실행에 시연 대상과 빈 기록으로 생성합니다. 테스트는 별도 DB로 실행하므로 첨부된 DB는 유지됩니다.

## 시연 순서

1. **안부전화 체험 → 전화 받기**를 누릅니다.
2. 몸 상태에 `오늘은 몸이 괜찮아요`라고 답합니다.
3. 식사 질문에 `아직 안 먹었어요`라고 답하면 이유를 한 번 더 묻습니다. 재질문에 `먹을 게 없어서 못 먹었어요`를 입력합니다.
4. 이후 차례대로 `어젯밤 잘 잤어요`, `약 챙겨 먹었어요`, `기분이 좋아요`를 입력합니다. 마지막 답변이 저장되면 자동으로 종료됩니다.
5. **통화 기록 → 상세 보기**에서 `추가 확인`, `식사 어려움`, 해당 발언을 확인합니다. 브라우저를 새로고침해도 기록은 남습니다.

질문 읽기와 음성 입력은 브라우저 기능을 사용합니다. 음성 입력을 쓰면 변환된 글자를 확인한 뒤 직접 전송합니다. 시연 대상과 예시 답변만 사용하세요. 실제 전화 발신과 119 자동 신고 기능은 포함하지 않습니다.

## 웹 화면 파일

`web/index.html`, `web/style.css`, `web/app.js`를 포함합니다. 별도 Node.js 설치나 프런트엔드 빌드 없이 위 실행 명령으로 접속할 수 있습니다.

생활지원사 화면에서 오늘의 현황과 진행 중인 통화 이어가기를, 안부전화 체험에서 질문별 답변·재질문·중단·수신 거절을, 통화 기록에서 판정 근거와 질문별 답변을 확인합니다. 질문 읽기는 브라우저 음성 합성, 음성 입력은 지원 브라우저의 마이크 권한이 필요하며 사용할 수 없으면 직접 입력합니다.
