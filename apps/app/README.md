# 안심온 앱 (어르신 폰)

어르신이 쓰는 전화 화면(PWA)이에요. 생활지원사 웹에서 "전화 걸기"를 누르면 이 앱에서 벨이 울리고,
AI가 다섯 가지(몸·식사·수면·약·기분)를 여쭤봐요. 말로 답해도 되고, 큰 버튼이나 글자로 답해도 돼요.

- 시안: `packages/design/preview-v3.html` ⑤ · 색·간격: `packages/design/tokens.css`(가져다 쓰기만 하고 고치지 않아요)
- API 약속: `packages/contracts/CONTRACT.md`의 `/api/elder/...`
- 주소: 개발 http://127.0.0.1:5181 · 서버(API)는 http://127.0.0.1:8010 으로 넘겨요(`/api` 프록시)

## 실행

### Windows PowerShell

```powershell
cd "C:\Users\User\Desktop\대학교\3학년\학습튜터링\DatAIve_2026-2\2팀\apps\app"
npm install
npm run dev            # 진짜 서버(apps/api, 8010)에 붙어요

npm test               # 음성 인식·읽기 단위 시험 (vitest)
npm run build          # 타입 검사 + 배포용 빌드 → dist/
npm run preview        # dist/를 http://127.0.0.1:5186 에서 확인 (서비스 워커 포함)
```

### WSL

```bash
cd "/mnt/c/Users/User/Desktop/대학교/3학년/학습튜터링/DatAIve_2026-2/2팀/apps/app"
```

- `node_modules`는 Windows와 WSL이 서로 못 써요(esbuild가 운영체제마다 달라요). 다른 쪽에서 실행하려면 `node_modules`를 지우고 `npm install`을 다시 하세요.
- WSL에서 `/mnt/c` 아래 파일을 고치면 자동 새로고침이 안 될 수 있어서, WSL일 때는 폴링으로 감시해요(`vite.config.ts`).
- 5173·5174·5175·8787·4173 포트는 다른 프로젝트가 써서 피했어요. 앱은 5181(개발)·5186(미리보기)을 써요.

## 처음 켜기

- 생활지원사 웹의 QR은 `http://<주소>:5181/r/KY-01` 같은 주소예요. 열면 그 어르신으로 정해지고 홈으로 가요.
- QR 없이 열면 "어느 어르신 폰인가요?" 화면이 나와요(**시연용**). 설정 → "다른 어르신으로 바꾸기"로 다시 고를 수 있어요.
- 홈의 "지금 전화 받기"는 **시연용**이에요. 생활지원사 웹의 "전화 걸기"와 같은 요청(`POST /api/staff/residents/{id}/call`)을 보내서 이 폰으로 벨을 울려요.

## 폰에 설치하기 ("홈 화면에 추가")

1. 폰과 컴퓨터를 같은 와이파이에 연결하고 `npm run dev`를 켜요(0.0.0.0으로 열려 있어요). 터미널에 나오는 `Network: http://192.168.x.x:5181` 주소를 폰에서 열어요.
2. 안드로이드 크롬: 오른쪽 위 ⋮ → **홈 화면에 추가**(또는 "앱 설치").
   아이폰 사파리: 아래 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면의 분홍 하트 아이콘으로 열면 주소창 없이 앱처럼 떠요.

### 마이크는 HTTPS나 localhost에서만 돼요

브라우저는 `http://192.168.x.x` 같은 주소에서 마이크를 막아요. 이때 앱은 **"마이크를 쓸 수 없어요 · 버튼이나 글자로 답해 주세요"** 를 띄우고, 큰 버튼과 "글자로 답하기"로 통화를 끝까지 할 수 있어요.
폰에서 말로 답하려면 다음 중 하나가 필요해요.

- HTTPS 터널(예: `cloudflared tunnel --url http://localhost:5181`)로 연 `https://…` 주소
- 안드로이드 크롬을 USB로 연결하고 `chrome://inspect` → Port forwarding(5181)으로 폰에서 `http://localhost:5181`
- 아이폰 사파리는 웹 음성 인식이 불안정해요. 버튼·글자로 답하는 걸 기본으로 생각해 주세요.

소개 페이지의 iframe 안에서 말로 답하려면 iframe에 `allow="microphone; autoplay"`가 있어야 해요.

## 환경 변수

| 이름 | 값 | 뜻 |
|---|---|---|
| `VITE_MOCK` | `1` | 서버 없이 `src/mock/mockApi.ts`의 가짜 API를 써요. `npm run dev:mock`이 `.env.mock`으로 켜요. 기본은 진짜 API. |
| `WSL_DISTRO_NAME` | (WSL이 자동 설정) | 있으면 파일 감시를 폴링으로 해요. |

API 주소는 `vite.config.ts`의 프록시(`/api` → `http://127.0.0.1:8010`)에서 바꿔요.

## 통화 흐름

벨(2초마다 `GET /api/elder/{id}/incoming`, 화면이 보일 때만) → 받기 → AI 말 읽기(TTS, ko-KR, 속도 0.86) →
**읽기가 끝나면 저절로 듣기**(설정에서 끌 수 있어요) → 다 들으면 `POST turn`(`source: 'stt'`) → 다음 질문 읽기 → … → 마무리 인사 → "오늘도 고맙습니다".

- 10초 동안 아무 말이 없으면 `source: 'silence'`(빈 글자)를 보내요. 브라우저가 그 전에 듣기를 끝내면 10초가 될 때까지 조용히 다시 들어요.
- 마이크와 읽기는 절대 동시에 켜지지 않아요(읽기 전에 마이크를 먼저 꺼요).
- 네트워크가 끊기면 "다시 보내기"가 나오고, 적은 글은 지워지지 않아요. 같은 답을 다시 보낼 때는 같은 `client_turn_id`를 써서 서버가 두 번 저장하지 않아요.
- 새로고침해도 진행 중인 통화가 있으면(`incoming.active`) 이어서 여쭤요.
- 벨이 30초 안에 안 받아져 서버가 미응답으로 바꾸면 홈에 "전화를 못 받으셨어요. 다음 전화를 기다려 주세요."가 떠요.
- 벨소리는 웹오디오(440+480Hz)로 내요. 브라우저가 막으면 "벨소리 켜기" 버튼이 나와요. 진동이 되는 폰은 함께 떨어요.

## 아직 가짜인 부분

- **가짜 API 모드**(`VITE_MOCK=1`)의 어르신 세 분, 지난 기록, AI 답(공감 문장·선택지·안전 신호)은 모두 대본이에요. 진짜 판정은 서버(`apps/api`)가 해요.
- **"지금 전화 받기"** 와 **어르신 고르기** 화면은 시연용이에요. 실제로는 생활지원사가 전화를 걸고, 어르신은 QR로 한 번 정해요.
- 앱이 꺼져 있을 때 벨을 울리는 **푸시 알림은 없어요.** 앱이 열려 있고 화면이 보일 때만 2초마다 확인해요.
- 진동·벨소리는 브라우저 정책에 따라 안 날 수 있어요(특히 아이폰).
- 새로고침 뒤 이어가기(`GET /api/elder/calls/{id}`)에는 선택지가 없어서, 그 질문은 말이나 글자로만 답해요.
- 서비스 워커는 배포용 빌드(`npm run build`)에서만 등록돼요. 앱 껍데기만 저장하고 `/api`는 항상 네트워크로 가요(오프라인에선 통화가 안 돼요).
