# 복지서비스 데이터 일부 (`welfare_subset.json`) — F11

통화에서 찾은 **어려움 유형**(식사 어려움 · 수면 문제 · 도움 요청 · 외로움)과 어르신의 **거주 지역**으로
연계할 만한 복지서비스를 생활지원사에게 보여 주는 데 쓴다. 서버는 이 파일만 읽으므로 인터넷 없이도 시연된다.

## 출처 (출처 표시 필수)

| 데이터 | 제공 | 공공데이터포털 ID |
|---|---|---|
| 지자체복지서비스 목록·상세 | 한국사회보장정보원 | [15108347](https://www.data.go.kr/data/15108347/openapi.do) |
| 중앙부처복지서비스 목록 | 한국사회보장정보원 | [15090532](https://www.data.go.kr/data/15090532/openapi.do) |

- 수집일: **2026-11-13** (`data_as_of`). 이후 바뀐 사업은 반영되지 않았다. 신청 전에 복지로 상세(`link`)에서 확인한다.
- 원본은 다른 과제에서 내려받아 둔 캐시(지자체 전국 4,828건 목록 · 서울 397건 상세 · 중앙부처 461건 일부)이며, 저장소에는 아래 규칙으로 고른 일부만 넣는다.
- 다시 만들기: `python scripts/build_welfare_subset.py <캐시 폴더>` (API 키를 쓰지 않는다)

## 필드

| 필드 | 원본 | 뜻 |
|---|---|---|
| `id` · `name` | servId · servNm | 서비스 ID · 이름 |
| `source` | – | `지자체복지서비스` 또는 `중앙부처복지서비스` |
| `ctpv` · `sgg` | ctpvNm · sggNm | 시도 · 시군구 (시군구가 없으면 시도 전체 사업, 중앙부처는 둘 다 없음) |
| `org` | bizChrDeptNm / jurMnofNm+jurOrgNm | 담당 부서·기관 |
| `summary` | servDgst | 서비스 요약 |
| `target` · `criteria` · `content` · `apply` | sprtTrgtCn · slctCritCn · alwServCn · aplyMtdCn | 지원대상 · 선정기준 · 지원내용 · 신청방법 (서울 상세가 있을 때만, 400자까지) |
| `apply_method` | aplyMtdNm | 신청 방식 (방문·인터넷 등) |
| `contact` | inqplCtadrList / rprsCtadr | 문의처 |
| `link` | servDtlLink | 복지로 상세 주소 |
| `needs` | – | 이 서비스가 맞는 어려움 유형 (아래 낱말 표로 계산) |

## 고르는 규칙

1. **어르신 대상**: 생애주기에 '노년'이 있거나, 이름·요약·지원대상에 노인·어르신·65세 이상·독거·홀로·홀몸이 있다.
   이름이 장애인·노숙인·한부모·아동·청소년·청년·보훈 등 다른 대상을 가리키면 (이름에 노인·어르신이 없는 한) 뺀다.
   기관 운영비·행사·장기요양 등급이 필요한 급여(가족요양비)는 뺀다.
2. **어려움 유형 낱말**(`app/domain/rules.yaml` `welfare.keywords`)이 이름·요약에 하나라도 있다.
3. **범위**: 서울특별시 전체(상세 포함) · 대전광역시 전체 · 중앙부처. 중앙부처 식사 지원은 노인 표시가 없어도 저소득·취약계층 전체 대상이면 넣는다(농식품바우처).

## 주의: 관심주제 태그는 믿지 않는다

원본의 관심주제(`intrsThemaNmArray`)는 품질이 낮다. '서민금융'이 65.6% 행에 붙어 있고, "저소득 어르신 무료급식"에 '입양·위탁'이 붙는 식이다.
생애주기(`lifeNmArray`)도 30%가 비어 있다. 그래서 **태그가 아니라 이름·요약의 낱말로** 고르고 연결한다.
낱말로 고른 것도 완벽하지 않으므로, 화면에는 "연계할 만한 지원(후보)"으로 보여 주고 결정은 생활지원사가 한다.

## 연결 순서 (`app/domain/matching.py`)

같은 시군구 → 같은 시도의 시도 전체 사업 → 중앙부처, 최대 3건. 다른 시군구 사업은 그 주민만 받을 수 있어 보여 주지 않는다.
어르신들이 이미 받고 있는 노인맞춤돌봄서비스는 뺀다. 지자체 사업이 없으면 note에 "중앙부처 서비스를 보여 드려요"라고 적는다.
