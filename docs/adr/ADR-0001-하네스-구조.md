# ADR-0001 하네스 구조 (apps · packages · docs)

- 상태: 채택 (2026-11-14)
- 배경: `ansimon-fullstack/`은 웹 한 개에 생활지원사 화면과 어르신 전화 화면이 섞여 있었고, 규칙·대화·DB 코드가 한 파일(main.py 22KB)에 몰려 버그가 반복됐다(질문 순서 꼬임, 위험 확인 갇힘, 미응답 없음, 방치된 통화).
- 선택: 서버 하나(`apps/api`) + 클라이언트 둘(`apps/web` 생활지원사, `apps/app` 어르신) + 공유 약속(`packages/contracts`) + 공유 디자인(`packages/design`). 서버는 domain(순수) / services(외부) / routers(HTTP)로 나눈다.
- 대안: 웹 하나에 경로만 나누기(이전 방식) — 화면·배포를 따로 다룰 수 없어 기각.
- 결과: 웹·앱·서버를 병렬로 만들 수 있다. 계약을 바꿀 때 세 곳을 같이 고쳐야 한다.
- 근거: 사용자의 이전 프로젝트 한벗(`apps/ packages/contracts docs/harness`), 이음등(`prototype/{llm,pipeline,api,web}`) 구조.
