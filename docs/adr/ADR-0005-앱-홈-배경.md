# ADR-0005 앱 홈 배경을 진주빛 추상 이미지로 교체

- 날짜: 2026-11-17
- 결정: 사용자 선택 및 원본 반영 요청

기존 갈색 거실 사진을 사용자 제공 진주빛 추상 이미지로 교체한다.
`apps/app-copy`에서 확인한 홈 디자인을 정식 앱 `apps/app`에 반영했다.

- 이미지: `apps/app/src/shared/assets/home-pearl.jpg`
- 적용: `apps/app/src/app/styles.css`의 `.lv-scene`
- 변경: 거실 사진·어두운 오버레이 제거, 이름표에서 '댁' 제거,
  안내 카드를 단정한 사각 카드로 정리하고 그림자를 줄임.
- 밝은 배경에 맞게 PC 휴대폰 프레임의 상태바 글자를 어둡게 표시.
- 기존 분홍색 버튼·하단 패널·통화 동작·API 계약은 유지.
- 이전 거실 이미지는 `home-night.jpg`로 보관.
- 사본은 비교용으로 남김. 기본 실행 대상은 `apps/app`, 개발 포트는 5181.

사용자가 원본 반영과 GitHub 업로드를 승인했다.
팀원은 main의 최신 변경을 받아 확인한다.
