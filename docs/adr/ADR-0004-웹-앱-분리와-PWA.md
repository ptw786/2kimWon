# ADR-0004 웹·앱 분리와 PWA

- 상태: 채택
- 배경: 생활지원사는 PC로 여러 어르신을 보고, 어르신은 폰 하나로 전화만 받는다. 시연에서 "웹에서 걸면 앱에서 울린다"를 보여야 한다.
- 선택: 어르신 앱은 PWA(QR → 홈 화면에 추가 → 앱처럼 실행). 웹 소개 페이지에 실제 앱을 폰 프레임으로 넣고, 실시간 통화 화면에 QR을 둔다.
- 대안: React Native/Expo 네이티브 — 코드베이스가 하나 더 생기고 STT/TTS를 다시 만들어야 해 일정상 기각. APK가 필요하면 같은 코드를 Capacitor로 감싼다.
- 결과: 마이크는 HTTPS나 localhost에서만 켜진다. 폰 시연에는 HTTPS 주소가 필요하다. 실제 서비스에서 어르신은 앱 대신 일반 전화를 받는다(제안서 6.가) — 앱은 그 전화를 시연하는 화면이다.
- 근거: 사용자의 이전 작업 몰통(QR + 홈 화면 추가), 제주잇 PhoneFrame, 함께반 QR 질문함.
