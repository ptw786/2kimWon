# ADR-0002 판정 규칙 r2 (같은 비중 + 추세 + 연락 상태)

- 상태: 채택, 라벨은 결정 대기(구현-계획 D1)
- 배경: v1은 항목 가중치 9·8·6·5·4에 근거가 없었고, 그날 통화만 보고, 미응답을 구분하지 못했고, "119"를 100점으로 섞었다.
- 선택: 다섯 항목 같은 비중(주의 5·위험 10) + 7일 추세(최대 30) + 연락 상태(최대 20). 안전 신호는 점수와 섞지 않고 최상위 단계로. 모든 점수에 이유와 인용.
- 대안: v1 가중치 유지 — 근거를 댈 수 없어 기각. 팀원이 minse 브랜치에서 만든 '0~15점 검토 점수'(11/14 커밋)는 아직 비교하지 않았다.
- 결과: 가중치는 가설이다. `docs/평가/`의 민감도 분석(±5)으로 순위 안정성을 보인다.
