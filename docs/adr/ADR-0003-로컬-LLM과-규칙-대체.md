# ADR-0003 로컬 LLM(Ollama ax4-light) + 규칙 대체

- 상태: 채택, 제안서 문구 결정 대기(구현-계획 D3)
- 배경: 규칙만으로는 "아침은 걸렀어. 입맛이 없어서" 같은 말에 맞는 반응과 다중 항목 추출이 어렵다. 통화 내용은 외부로 보내지 않는 것이 좋다.
- 선택: Windows의 Ollama `ax4-light:q4_K_M`(한국어 특화, 예열 후 0.2~0.5초). AI는 항목·상태·인용 추출과 공감 한 문장, 요약만 한다. 다음 행동·점수·안전 신호는 코드가 정한다. 시간 초과(추출 4초·공감 3초·요약 8초)·형식 오류면 키워드 규칙으로 대체하고 `ai_runs`에 남긴다.
- 대안: 클라우드 LLM — 개인정보·비용 문제로 기각. 규칙만 — 'AI 혁신성' 약함.
- 결과: Ollama가 없어도 끝까지 동작한다(`ANSIMON_LLM=off`). 실제 스모크에서 한 턴 0.24~1.3초.
