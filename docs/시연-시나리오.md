## 미리 확인할 것
- `http://127.0.0.1:8010/api/health` → `llm.reachable: true` (아니면 규칙 모드로도 끝까지 됨 — 사이드바에 '규칙 판정 모드' 표시)
- Ollama 첫 응답은 3~4초 걸릴 수 있다 → 시연 직전에 한 번 통화해 예열하고 데모 리셋
- 앱 벨소리가 안 나면 벨 화면의 '벨소리 켜기'
- 폰으로 시연하려면 HTTPS 주소가 필요하다(마이크). 노트북 두 창으로 하면 그대로 된다.

## 실패 대비
- 음성 인식이 안 되면: 앱의 큰 버튼이나 '글자로 답하기'로 같은 답을 넣는다.
- Ollama가 멈추면: 자동으로 규칙 판정으로 넘어간다(AI 실행 기록에 '규칙 대체'로 남음).
- 녹화본: 시연 전날 위 순서로 한 번 녹화해 둔다.
