# 안심온 디자인 v3

> 시안: `packages/design/preview-v3.html` · 토큰: `packages/design/tokens.css`
> 원칙: 사용자가 이전에 만든 대시보드·앱의 작업 방식을 그대로 이어 쓴다. 색만 분홍·버터로 바꾼다.

## 금지
- **카드·인용·행 왼쪽 색 선 쓰지 않음** (사용자 지정). 강조는 배경색·테두리 전체·배지로 한다. 타임라인의 세로 연결선은 예외.
- 글자 크기: 웹 16px 미만, 앱 20px 미만 금지.
- 상태를 색만으로 구분하지 않음 → 항상 아이콘 + 한글 라벨.
- 빨강은 '즉시 확인(긴급)'에만. **예외:** 전화 '안 받기'·'끊기' 버튼과 앱의 '도움 받기'·'119' — 실제 휴대폰 관례이며 사용자가 승인한 시안(벨 화면)과 같다(2026-11-14).
- 넓은 화면에서 앱은 실제 폰 크기(393×852) iframe을 폰 프레임에 넣어 축소해 보여 준다(`apps/app/src/app/DeviceFrame.tsx`). 실제 폰·iframe 안에서는 전체 화면.
