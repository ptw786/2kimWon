# 안심온 안부전화 시연

첨부한 HTML의 통화 화면과 5문항을 사용합니다. 한국어 답변 판정과 점수 계산은 서버에서 실행되며, 예약과 통화 결과는 SQLite에 저장됩니다.

## Windows에서 실행

1. ZIP을 압축 해제합니다.
2. VS Code에서 `server.py`가 들어 있는 `ansimon` 폴더를 엽니다.
3. VS Code에서 **터미널 → 새 터미널**을 열고 아래 명령을 실행합니다. Python 3.10 이상이 필요합니다.

   ```powershell
   py server.py
   ```

   `py` 명령을 찾을 수 없고 `python` 명령은 설치되어 있다면 `python server.py`를 실행하세요.

4. 브라우저에서 [http://127.0.0.1:8000](http://127.0.0.1:8000)을 엽니다. 서버를 켜 둔 동안 매일 예약이 처리됩니다. 테스트를 마치면 터미널에서 `Ctrl+C`로 서버를 종료합니다.

외부 API 키와 추가 패키지 설치는 필요 없습니다. 이 폴더에 `ansimon.sqlite3`가 처음 실행할 때 생성됩니다. 원본 HTML에서 브라우저에 저장한 기록은 자동으로 가져오지 않습니다.

## 빠른 시연

- **판정 확인** · 전화를 받은 뒤 `괜찮아요` → `오늘 밥을 못 먹었어요` → `잠을 못 잤고 밥도 못 먹었어요` → `약은 챙겼어요` → `기분은 괜찮아요`를 순서대로 입력하세요. 통화가 끝나면 식사 12점과 수면 8점, 총 20점으로 **우선 확인**에 표시됩니다.
- **예약 확인** · **매일 안부전화 예약**에서 가상 대상 별칭과 현재 한국 시간보다 1~2분 뒤 시각을 입력하세요. 시간이 되면 **대기 중인 예약 통화**에 나타납니다. **예약 통화 열기**를 눌러 수신 또는 거절하면 대상 별칭과 함께 기록이 저장됩니다.
- **저장 확인** · 새로고침하거나 같은 폴더에서 서버를 다시 실행하면 예약과 통화 기록을 확인할 수 있습니다.

## 판정 및 점수

| 항목 | 가중치 | 판정 예시 |
|---|---:|---|
| 몸 상태 | 9 | 피곤함 1단계, 어지러움 2단계, 넘어짐 표현 3단계 |
| 복약 | 8 | 복약 누락 표현 2단계 |
| 식사 | 6 | 끼니를 거른 표현 2단계 |
| 기분 | 5 | 외로움 표현 2단계 |
| 수면 | 4 | 잠을 못 잔 표현 2단계 |

- 문항과 답변을 함께 봅니다. 예를 들어 식사 문항의 짧은 답변 `아니요`는 식사 신호로 처리합니다. 모호하거나 문항과 관련된 답을 확인하기 어려우면 해당 항목에 1단계를 적용합니다.
- 항목 점수는 **가중치 × 단계**입니다. 한 답변에서 여러 항목을 감지할 수 있습니다. 여러 답변에서 같은 항목이 반복되면 가장 높은 점수만 합산합니다.
- 수신 거절 또는 답변 없이 종료되면 20점, 일부 답변 후 중단되면 10점을 더합니다.
- 총점 **0점**은 특이 표현 없음, **1~19점**은 추가 확인, **20~99점**은 우선 확인입니다. `119 불러줘` 같은 즉시 확인 표현은 총점 **100점**으로 표시합니다.
- 위 기준은 시연용 휴리스틱입니다. 사전에 정한 표현과 일부 부정·과거 표현만 다룹니다. 점수는 생활지원사가 답변을 살펴볼 순서를 정하는 데 사용합니다.

## 스케줄 처리

예약은 한국 시간 기준으로 매일 반복됩니다. 해당 시각이 지난 상태에서 등록하면 다음 날부터 시작합니다. 서버는 매초 예약을 확인하고, 예약과 예정 시각의 조합마다 대기 회차를 한 번만 만듭니다. 예약 시각에 서버가 꺼져 있으면 재시작 시 놓친 회차 중 가장 최근 회차를 복구합니다. 예약 수정·삭제 시 해당 예약의 미처리 회차를 정리하며 완료된 통화 기록은 보관합니다. 통화 기록의 **기록 지우기**는 결과 기록만 지웁니다.

예약은 시연 화면의 통화 대기 목록에 연결됩니다. 실제 전화 발신과 자동 신고는 구현 범위 밖입니다. 테스트에는 가상 별칭과 예시 답변을 사용하세요.
