# 예약 기능 제거 및 안부전화 오류 수정

검증일: 2026-11-13 (한국 시간). 기존 React/FastAPI/SQLite 구조와 minse 통화 기록을 유지했다.

## 실제 수정

1. 예약 화면·메뉴·API·백그라운드 스케줄러 및 전화 훅의 예약 연결을 제거했다. 이전 예약 URL에는 종료 안내를 표시하고 queue_id API 요청은 422로 거부한다. 일반 전화 체험은 유지한다.
2. DB 시작 백업 후 scheduled_calls의 과거 별칭·예정 시각을 calls로 옮기고 scheduled_calls/care_schedules를 삭제한다. Savepoint로 묶어 중간 실패 시 이전·삭제를 모두 롤백한다. 재시작 시 테이블을 재생성하지 않는다.
3. 수면 질문의 어/네네, 기분 질문의 좋아/별로야/별로 안 좋아와 짧은 부정·중립 표현을 해석한다. 잤어는 수면 사실만 중립 확정하고 quality=unconfirmed를 보존한다. 잠을 편히 잤다고 만들어 말하지 않는다.
4. 재질문을 한 번에 한 가지 긍정형 질문으로 바꿨다. 열린 질문·과거 양자택일·일상 대화의 단순 응/어를 임의로 사실 확정하지 않는다. 원래 기본 5문항 문구는 유지한다.
5. 새 답변부터 실제 직전 질문을 turns/turn_attempts에 저장한다. 과거 잘못 저장된 질문은 실제 발화 근거가 없어 소급 추정하지 않는다.
6. API 오류에 HTTP 상태를 유지한다. 답변의 409 충돌은 서버 상세를 다시 조회해 복원한다. 다른 질문에 쓰던 원문은 별도 표시하며 새 질문에 자동 전송하지 않는다.
7. 초안·저장 여부 미확인 요청을 통화/질문/시도별 sessionStorage에 보존한다. 새로고침 후 원문과 재시도 버튼을 복원한다. 서버에 이미 저장된 같은 답변이면 재전송하지 않는다. 명시적 통화 종료 시 초안을 정리한다. 저장소 차단 시 보존 불가를 안내한다.
8. 이전 taewon 기록 가져오기는 기록·원점수·원본 통계 아카이브를 유지하되 활성 예약을 복구하지 않는다. 화면의 예정 시각 열도 제거했다.

사용자가 보고한 짧은 답변 실패, 양자택일 후 응의 오판정, 실제 질문 저장 불일치, 409 반복 실패는 수정 전 별도 API/브라우저 검사에서 재현했다. 이번 자동 검사에는 그 사례들을 포함했다. 수정 전 실패나 재현된 결함이 없었다고 주장하지 않는다.

예약 기능이 없어져 기존 예약 생성/스케줄러 동작 검사 11개 사례를 제거하고, 예약 제거·마이그레이션·기록 보존 검사를 추가했다. 나머지 기존 대화·기록·점수·STT/TTS·벨소리·서버 중단/복구·재시도 검사는 유지한다. 실제 테스트 성공은 해당 시나리오에 대한 결과이며 모든 입력·환경에서 무오류를 보장하지 않는다.

## 미검증 및 제한

- 실제 마이크 한국어 STT, 한국어 TTS·벨소리 청감, Windows 직접 실행은 미검증이다. native Chromium 음성 API를 시도했지만 입력 장치·한국어 음성은 각각 0개였다. 정상 음성 제어는 모의 이벤트로 검사한다.
- 실제 사용자 PC DB를 변경하지 않았다. 해당 PC에서 새 백엔드를 시작할 때 백업과 예약 제거 마이그레이션이 적용된다. 기존 백엔드 프로세스를 Ctrl+C로 종료하고 새 버전을 실행해야 한다.
- 초안은 탭 단위 임시 저장이다. 브라우저/탭을 닫거나 저장소가 차단된 경우 보존을 보장하지 않는다. 저장 성공·명시적 종료 후 해당 초안을 정리한다.
- 자유 생성 AI나 임상 평가를 제공하지 않는 규칙 엔진이다. 사투리·복합 부정·간접 표현을 모두 해석하지 못하며 불확실한 내용은 확인 대상으로 남긴다.
- 큰 기록 목록의 점수 계산과 페이지네이션은 별도 성능 개선 대상이다.

## 실행

기존 두 터미널을 종료한 뒤 최신 minse의 ansimon-fullstack 폴더에서 실행한다. 처음 설치하는 경우 README의 가상환경·의존성 설치를 먼저 수행한다.

```powershell
# 터미널 1: 프로젝트 루트
Set-Location .\backend
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

```powershell
# 터미널 2: 프로젝트 루트
Set-Location .\frontend
npm.cmd ci
npm.cmd run dev
```

http://127.0.0.1:5173/ 에서 체험한다. DB가 있는 폴더의 backup 파일을 삭제하지 말고, 기존 기록과 점수를 확인한다. 새로운 DB로 바꿔 오류를 숨기지 않는다.
